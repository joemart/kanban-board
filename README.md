## Overview

A website intended to keep track of all the tools that you might need to keep track of!

## How do I use it

To start using the Kanban board, register an account or log in if you already have an account. 

## Boards

### Add
Click on <button>Add Projects +</button> to add a board. Type in the name of your board.

### Remove

On the sidebar, click on <button>Projects</button>, then click on <span style="background-color:white;  display:inline-block"><img src="https://lucide.dev/api/icons/trash-2" width="24" height="24"></span> to delete.


### Update

On the sidebar, click on <button>Projects</button>, then click on <span style="background-color:white;  display:inline-block"><img src="https://lucide.dev/api/icons/pencil" width="24" height="24"></span> to edit.

## Columns

### Add

Click on <button>Add column</button> and type in a name for the column.

### Remove

Right click on the column and select <button>Delete</button>.

### Update

Right click on the column and select <button>Edit</button>.

## Cards

### Add

Click on <button>Add card</button> and type in a name for the card.

### Remove

Right click on the card and select <button>Delete card</button>.

### Update

Right click on the card and select <button>Edit</button>.
